# 収録資料について

`manual.md` は、「会計年度任用職員制度の運用に係る事務処理マニュアル」（令和8年10月、総務省自治行政局公務員部）をMarkdown化したものです。令和8年3月版からの変更は、新旧対照表（別紙2）に基づいて反映しました。

公開元: [総務省｜会計年度任用職員制度等](https://www.soumu.go.jp/main_sosiki/jichi_gyousei/koumuin_seido/kaikeinendo_ninyou.html)

- 令和8年3月版の原PDF全113ページをMarkdown化した本文・図表・注記・参考資料を基に、令和8年10月版（全114ページ）の新旧対照表で示された変更を反映しています。
- Markdown化の際にページ境界が除かれているため、このWebアプリではMD行番号と問番号・章節を根拠位置として表示します。
- 公開用Markdownでは、長文を読みやすくするため、本文の意味・文字順を変えずに句点単位の改行を追加しています。
- 正式な内容確認では、総務省が公開する原資料を参照してください。
