## 確認した事実

- 対象MDは令和8年3月版のMarkdownを基に、令和8年10月版（原PDF全114ページ）の変更を反映した。
- 目次上、Q&Aは21分類で構成される。
- 令和8年10月版の独立したQ&A見出しは112件。問17－1の新設によって令和8年3月版から1件増えた。
- MDはページ境界を除いているため、現段階では正確なPDFページリンクを自動生成できない。
- GitHub Pagesは静的配信であり、秘密のAPIキーや非公開データを保持する場所にはしない。

## 設計上の解釈

- 公式Q&Aの原文提示を第一とし、本文検索を補助にする。
- 行番号はMD内の追跡用であり、正式なページ番号の代替とは表示しない。
- 第1段階では閲覧者の検索語を外部へ送信しない。
